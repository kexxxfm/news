Подключение к GitHub

Нужен токен доступа (создаётся один раз, шаги на вкладке «Помощь»). Он хранится только в этом браузере и отправляется только на api.github.com.

Управление

Выпуск собирается заранее и публикуется в :30 перед эфиром (каждые 2 часа). Время меняется в hourly.yml. Пауза выпусков — в «Настройки → Публикация».

Последние запуски

Выпуски

Вступят в силу со следующего выпуска.

Загрузите свои звуки (mp3/wav, до 20 МБ). Загруженный файл заменяет звук пакета для этого типа во всех частях суток; если ничего не загружено, играет пакет по времени суток. Файлы попадают в публичный репозиторий — загружайте только то, на что у вас есть права.

Как получить токен

  1. GitHub → ваш аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Название любое, срок — до 1 года. Repository access → Only select repositories → выберите репозиторий подкаста.
  3. Permissions → Repository permissions: Contents — Read and write и Actions — Read and write.
  4. Нажмите Generate token, скопируйте (показывается один раз) и вставьте при подключении.

Токен даёт запись только в этот репозиторий. Не вводите его на чужих компьютерах. Если потерян — отзовите на странице токенов GitHub.

Как это работает

Панель сохраняет настройки в файл config.json репозитория и кладёт звуки в папку assets/. Бот читает их при каждом выпуске. Расписание (каждые 2 часа) меняется в hourly.yml.
